# Akshay Bhave — Engineering Portfolio

A responsive, static portfolio site designed for GitHub Pages. It contains no build step or backend dependency.

## Files
- `index.html` — main portfolio
- `composite-laminate.html` — detailed CFRP project case study
- `styles.css` — site styling
- `script.js` — mobile navigation

## Publish with GitHub Pages
1. Create a new **public** GitHub repository named `akbhv.github.io` (for a user site), or any repository name if you prefer a project site.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to finish publishing. For a user site, the expected URL is `https://akbhv.github.io/` if the repository is named `akbhv.github.io`; otherwise the project URL includes the repository name.
