ML Surrogate Model for Composite Laminate Failure Prediction

An end-to-end engineering project that brings together composite laminate mechanics, physics-based failure analysis, a deep neural network surrogate, and a web application for making predictions accessible.

01 / THE PROBLEM

Connect engineering physics with fast prediction.

Composite laminate failure analysis requires mechanical modelling and evaluation of failure criteria. This project builds a physics-based reference framework and trains a machine-learning surrogate to approximate its predictions, then wraps the workflow in a web application.

Engineering challenge

Represent laminate behaviour and failure assessment consistently enough to generate a useful synthetic dataset and reference predictions.

Project objective

Develop a complete pipeline—from physics-based calculations to a trained model and user-facing prediction interface.

02 / METHODOLOGY

From mechanics to an accessible application.

STEP 01Composite laminate mechanics
STEP 02Physics-based failure framework
STEP 03Synthetic data generation + DNN
STEP 04API + web interface

Physics-based framework

Implemented Classical Lamination Theory (CLT) and a framework spanning maximum stress, maximum strain, Tsai–Hill, Tsai–Wu, Hashin and related failure formulations represented in the project workflow. The physics-based implementation provides the reference outputs used to create training data and evaluate the surrogate.

Dataset and surrogate model

Generated 20,000 synthetic samples using the physics framework and trained a deep neural network (DNN) to approximate the reference predictions. Evaluation included a held-out test set and an independent unseen-data check.

Full-stack application

Built a FastAPI backend and React frontend, connecting the prediction workflow to a web interface. This makes the project more than a standalone model: it includes an application layer for user interaction.

04 / RESULTS AND INTERPRETATION

Strong agreement with the reference model.

The project report records a held-out test R² of 0.998562 and an independent unseen-data R² of 0.999208. These values indicate that the surrogate closely reproduces the outputs of the physics-based reference framework on the evaluated data.

Important scope note: these metrics describe agreement with the computational reference model. They should not be presented as experimental validation against physical laminate tests.

05 / LIMITATIONS AND NEXT STEPS

Good engineering includes knowing what remains.

  • Validate predictions against experimental composite-laminate data.
  • Investigate prediction errors and model behaviour at high failure-index values.
  • Assess coverage across a broader range of materials and laminate configurations.
  • Document model assumptions, input ranges, and applicability limits clearly in the application.
